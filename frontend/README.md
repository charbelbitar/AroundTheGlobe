React + Vite frontend 

## Local development
1. Copy `.env.example` to `.env`
2. Make sure the Express backend is running at `http://localhost:1337`
3. Install dependencies (npm install)
4. Start Vite (npm run dev) - the frontend will run on `http://localhost:5173`

## Main routes
- `/` Home
- `/flights` Available flights
- `/login` Login
- `/register` Register
- `/bookings` Authenticated user's bookings
- `/admin` Admin flight management
